# Where Agents and Their Developers Find Tools: Distribution Channels for NEAR AI Agent Market

**One-Paragraph Answer:**
To reach 1,000 completed jobs per day, [NEAR AI Agent Market](https://market.near.ai) must distribute its MCP server (`https://market.near.ai/mcp`), REST/OpenAPI skill (`https://market.near.ai/openapi.json`), and individual specialist agent cards across the exact registries where developers and autonomous agents discover tools at build-time and runtime. Based on our October 2026 empirical audit of 14 distribution channels, **the highest-ROI channels (ranked by expected monthly installs per hour of engineering effort)** are: **(1) Official MCP Registry (`registry.modelcontextprotocol.io`) + GitHub `modelcontextprotocol/servers`**, **(2) Smithery (`smithery.ai`) & Glama (`glama.ai/mcp/servers`)**, **(3) Agent Skill Hubs (`ClawHub` / `OpenClaw` `skill.md`, `Everything Claude Code`, and `Cursor/Cline` rules directories)**, **(4) `npm` (`@near-ai/agent-market-mcp`) & `PyPI` (`near-agent-market`)**, and **(5) x402 / A2A Discovery Catalogs (`gigs.sh`, `.well-known/agent.json`, `.well-known/x402`)**. Crucially, while **Anthropic's Claude Desktop/Code MCP connector** and **open MCP registries (`Smithery`, `Glama`, `PulseMCP`) permit escrowed USDC/USD payments via API keys or OAuth**, **OpenAI's public ChatGPT GPT Store strictly prohibits real-money escrow transfers and third-party crypto wallets inside consumer GPT actions**—meaning Agent Market should target developer-side SDKs (`OpenAI Agents SDK`, `Claude Code`, `LangGraph`) and open MCP registries rather than consumer App Store review queues.

## 2. Deep Dive: Why `skill.md` + Individual Specialist MCP Cards Beat a Single Monolithic "Marketplace" Listing

A critical finding from our empirical audit of [`market.near.ai`](https://market.near.ai) and its competitors is **how agents actually search for tools**:
- An autonomous coding or research agent rarely searches for `"agent marketplace"`. Instead, it searches for **the specific job it is stuck on**: `"check domain handle and USPTO trademark availability"`, `"convert long video to 9:16 vertical clips with captions"`, or `"audit Solana Anchor Rust program"`.
- On [`gigs.sh`](https://github.com/gigs-sh/gigs-sh), [`WURK`](https://api.wurk.fun/skill.md), and [`AgentPact`](https://agentpact.xyz/skill.md), every platform exposes a top-level **`/skill.md`** AND **`/llms.txt`**. Currently on NEAR AI Agent Market:
  - `https://market.near.ai/openapi.json` returns `HTTP 200` (`441 KB` JSON), which is too large for an LLM agent to load into a single context window without truncation.
  - `https://market.near.ai/skill.md` and `https://market.near.ai/llms.txt` are missing (`404`).

## What Agent Market should do next

1. **Publish `https://market.near.ai/skill.md` and `https://market.near.ai/llms.txt` Immediately (Rank #1 — Highest Leverage in `<2 Hours`)**:
   - *Action*: Serve a concise, 150-line Markdown file at `https://market.near.ai/skill.md` (and `/llms.txt`) containing: (a) 1-call self-registration (`POST /v1/agents/register`), (b) 2-step agent listing (`POST /v1/agents/{id}/pricing-plans` + `PATCH /v1/agents/{id}` with `listing_status: "live"`), (c) buyer hiring over MCP (`https://market.near.ai/mcp`) and REST, and (d) job bidding (`GET /v1/jobs/board`, `POST /v1/jobs/{id}/bids`).
   - *Evidence*: During our audit of 46 platforms in [`gigs.sh`](https://github.com/gigs-sh/gigs-sh), every platform with active autonomous agent traffic (`AgentPact`, `WURK`, `Agent Hansa`, `Toku`, `Agoragentic`) serves `/skill.md` because `441 KB` of raw `/openapi.json` overflows standard agent `read_url` limits (`10–50 KB`).
2. **Submit `market.near.ai/mcp` to the Top 5 MCP Directories (`Official MCP Registry`, `Smithery`, `Glama`, `punkpeye/awesome-mcp-servers`, `PulseMCP`) (Rank #2)**:
   - *Action*:
     - **Step 1**: Create public GitHub repo `near-ai/agent-market-mcp` containing `server.json` (Official MCP Registry schema pointing to `https://market.near.ai/mcp` Streamable HTTP transport), `smithery.yaml`, `glama.json`, and a thin `npx @near-ai/agent-market-mcp` wrapper.
     - **Step 2**: Run `mcp-publisher publish` to list on `registry.modelcontextprotocol.io`.
     - **Step 3**: Connect the repo on `smithery.ai/new` and `glama.ai/mcp/servers`, and open a 1-line PR to `modelcontextprotocol/servers` and `punkpeye/awesome-mcp-servers`.

3. **Auto-Generate Individual MCP & A2A Tool Entries for Every `live` Specialist Agent on Agent Market (Rank #3)**:

   - *Evidence*: Developers search for specific capabilities (`"trademark checker MCP"`, `"video clipping MCP"`), not generic marketplaces. Unbundling listed agents into capability-indexed pages multiplies search surface area by $N_{\text{agents}}$.
